# Hermes 用于策略研究的适用性

## 2026-10-08：讨论，未批准实施

用户提到此前 Few Understand 使用 Hermes 开发太慢，询问只用 Hermes 做策略是否更合适。本轮没有找到此前 Hermes 讨论的仓库记录，也没有检查其部署、模型配置或运行日志；开发慢是用户报告，原因未验证。此处暂按 Nous Research 的 Hermes Agent 理解，“策略”暂按信号与交易策略的研究、假设设计和复盘理解；若指产品战略或实时交易决策，需另行界定。

核对 [Hermes 官方文档](https://hermes-agent.nousresearch.com/docs/)：产品提供跨会话记忆、可复用技能、定时任务、模型提供方配置与工具接入。这是官方能力说明，不是本项目运行验证，也不证明策略质量或盈利能力。

助手判断：Hermes 值得作为长期策略研究助手评估。记忆有助于保留研究定义、历史实验和失败原因，技能有助于重复执行研究流程，定时任务有助于持续复盘。但策略推理质量仍依赖所选模型、输入证据和评价方法，保存经验也可能保存错误。若仅偶尔讨论想法，其部署与维护成本未必值得；若要求实时、稳定、可复现的评分或执行，应由确定性程序承担。

候选分工：Hermes 阅读真实采集记录，提出信号假设、反例及验证方案，调用已有分析/回放工具并解释结果；SignalStudio 保存经过确认的定义与版本；Few Understand 按明确规则采集、计算并回报运行证据。这是建议，不改变现有应用或执行契约。

示例研究任务：检查升温榜误报，区分转载重复、低基数和来源恢复，提出一项可检验的修订。研究输出应包含依据、反证、验证方法和未确定项；不能把自动写入技能的经验当作已验证规则。

建议用同一批历史材料、相同底层模型比较现有流程与 Hermes，观察可验证假设数量、证据错误、重复劳动、人工修正时间以及延迟和费用。没有进行该比较，也没有批准接入、后台任务或自动交易。
